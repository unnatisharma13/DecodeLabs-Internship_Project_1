# Frontend Development Project 1 – Static Webpage Design

## Overview

This project is a static webpage developed using HTML5 and CSS3 as part of the DecodeLabs Frontend Development Industrial Training Program.

The objective of the project is to demonstrate the fundamentals of frontend development by creating a clean, structured, and responsive webpage using semantic HTML and modern CSS layout techniques.

---

## Features

* Semantic HTML5 structure
* Responsive webpage design
* Navigation bar
* Hero section with Call-to-Action button
* Content grid with image cards
* Footer with contact information
* CSS Grid for page layout
* Flexbox for navigation alignment
* External stylesheet implementation

---

* CSS3
